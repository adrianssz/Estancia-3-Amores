# Frontend - Estância 3 Amores

Site destinado aos clientes da Estância 3 Amores.

O Frontend foi desenvolvido com React e Vite e utiliza Supabase para consultar os dados utilizados nas páginas do sistema.

## Páginas principais

O site possui:

- Home
- Feira
- Sobre Nós
- Contato
- Cesta
- Página de rota não encontrada

## Pré-requisitos

Para executar o Frontend é necessário possuir:

- Node.js
- npm
- acesso às configurações do projeto Supabase
